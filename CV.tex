\textbf{SusVibes: Benchmarking Secure Coding Agents} \hfill Jun. 2026 -- Present \titlebreak
Developing a repository-level benchmark for evaluating whether code patches generated by LLM coding agents are both functionally correct and secure. The project examines whether an agent can solve a software-engineering task without introducing security vulnerabilities into the codebase.
\begin{itemize}[nosep, topsep=\intraProjectListTopSep]
    \item Constructing security-focused repository-level tasks and extending the evaluation pipeline to jointly assess task completion and patch security, providing a foundation for larger-scale coding-agent training and evaluation.
\end{itemize}

\projectsep

\textbf{SeekJudge: Reward Modeling for Computer-Use Agents} \quad \href{https://github.com/ZJUSCL/SeekJudge}{[GitHub]} \hfill Mar. 2026 -- May 2026 \titlebreak
Developed a practical reward framework for computer-use agents that evaluates whether an agent completed a task from its screenshots and actions, then converts the evaluation into training signals for reinforcement learning.
\begin{itemize}[nosep, topsep=\intraProjectListTopSep]
    \item Designed a four-agent judging pipeline---Condense, Ground, Seek, and Analyze---that processes screenshots and action sequences through a Seek--Analyze loop to determine whether long-horizon GUI tasks were completed.
    \item Built a reusable trajectory-processing and HTTP reward-serving pipeline supporting both offline batch evaluation and online RL training, with trajectory-level rewards and step-level quality judgments.
\end{itemize}

\projectsep

\textbf{TradeActor: Multimodal Stock Forecasting and Portfolio Learning} \hfill Mar. 2026 -- May 2026 \titlebreak
Built a system that combines stock charts, numerical data, and news to forecast DOW-20 stocks and make daily portfolio allocation decisions.
\begin{itemize}[nosep, topsep=\intraProjectListTopSep]
    \item Generated and evaluated LLM-based trading signals, then trained a Qwen-based portfolio policy with return and transaction-cost objectives.
    \item Integrated the policy into StockBench for end-to-end portfolio backtesting.
\end{itemize}

\projectsep

\textbf{TimeThinkingLLM: Multimodal Time-Series Reasoning} \hfill Sep. 2025 -- Jan. 2026 \titlebreak
Built a framework that connects continuous time-series signals with language-model reasoning.
\begin{itemize}[nosep, topsep=\intraProjectListTopSep]

    \item Trained and evaluated the model with GRPO on time-series reasoning benchmarks.
\end{itemize}
