\projectheading{AuraForge：代码智能体安全评测与训练}{2026.06 -- 至今}
\affiliation{Li Lab}
\begin{itemize}
    \item \textbf{研究目标：}结合功能测试与安全测试评估仓库级代码补丁，研究通过\textbf{安全监控模型（Monitor）}识别执行风险并辅助智能体决策，在保持功能正确性的同时提升代码安全性。
    \item \textbf{个人贡献：}构建任务构造流水线，从公开的 GitHub 安全公告（GHSAs）中提取漏洞修复提交，转换为配备功能测试和安全测试的仓库级任务，支持\textbf{功能正确性与补丁安全性的联合评估}。
\end{itemize}

\projectsep

\projectheading{SeekJudge：计算机操作智能体的奖励建模}{2026.03 -- 2026.05}
\affiliation{ZJU Scaling Logger（ZJUSCL）}
\begin{itemize}
    \item \textbf{研究问题：}面向长程 GUI 任务的完成度评估，为智能体强化学习提供模型奖励。项目将多智能体评判能力蒸馏至\textbf{9B 评判模型}，在在线强化学习中达到或超过基于规则的奖励效果。
    \item \textbf{个人贡献：}开发 Condense--Ground--Seek--Analyze 评判流水线，通过\textbf{Seek--Analyze 迭代循环}从长截图序列与操作序列中提取证据，判断任务是否完成。
    \item \textbf{系统实现：}构建轨迹处理与\textbf{HTTP 奖励服务流水线}，支持离线批量评估和在线强化学习。
\end{itemize}

\projectsep
