\affiliation{Li Lab}
\cvlabel{Project Overview:} A repository-level framework for evaluating and improving coding-agent security. It uses \textbf{functional and security tests} to determine whether generated patches satisfy task requirements without introducing vulnerabilities, and trains a \textbf{safety monitor} to identify potential risks and provide warnings to coding agents.

\cvlabel{My Contribution:}\par\nopagebreak
\begin{itemize}
    \item Built a \textbf{task-construction pipeline} that extracts vulnerability-fixing commits from public \textbf{GitHub Security Advisories (GHSAs)} and converts them into repository-level coding-agent tasks with functional and security tests, enabling joint evaluation of task completion and patch security.
\end{itemize}

\projectsep

\projectheading{SeekJudge: Reward Modeling for Computer-Use Agents\enspace {\small\normalfont\color{CVMuted}\href{https://github.com/ZJUSCL/SeekJudge}{[GitHub]}}}{Mar. 2026 -- May 2026}
\affiliation{ZJU Scaling Logger (ZJUSCL)}
\cvlabel{Project Overview:} A practical model-based reward framework that replaces brittle rule-based supervision for computer-use agents. It uses four role-specialized agents---Condense, Ground, Seek, and Analyze---to verify long-horizon GUI trajectories through an iterative Seek--Analyze loop, and distills their capabilities into a specialized \textbf{9B judge model} that matches or surpasses rule-based rewards in \textbf{online reinforcement learning} while providing step-level judgments at lower cost.

\cvlabel{My Contributions:}\par\nopagebreak
\begin{itemize}
    \item Developed the \textbf{Condense--Ground--Seek--Analyze judging pipeline}, using a Seek--Analyze loop to gather evidence from long screenshot and action sequences and determine task completion.
    \item Built the trajectory-processing and \textbf{HTTP reward-serving pipeline}, supporting offline batch evaluation and online reinforcement learning.
\end{itemize}
