\textbf{TradeActor} \hfill 2026.3 -- 至今 \titlebreak
项目描述：本项目面向\textbf{股票预测与组合策略学习}场景，旨在构建从多模态股票信号生成、VLM预测评估、策略教师标签构造到组合策略训练与回测验证的完整流程。项目以 \textbf{DOW-20} 股票为研究对象，结合历史价格图、数值摘要与新闻窗口生成预测样本，并训练基于 \textbf{Qwen} 的 Portfolio Policy，实现对每日 \textbf{cash + 20 stocks} 的目标仓位预测。
\begin{itemize}[nosep, topsep=\intraProjectListTopSep]
    \item \textbf{预测样本生成}：针对 \textbf{DOW-20} 股票，基于历史价格图、数值摘要与新闻窗口构造 rollout 样本，并调用 \textbf{Qwen/Gemini} 等模型生成结构化 \textbf{JSON} 信号，包括上涨概率、24日收益分位数、long/short/flat 交易倾向及置信度。
    \item \textbf{VLM信号评估}：系统统计 \textbf{valid rate、5/10/24日方向准确率、概率误差、分位数覆盖率} 与 bias\_strength 分桶效果，验证 VLM 股票预测信号的有效性；实验发现整体信号偏弱，但高 bias\_strength 子集具备一定筛选价值。
    \item \textbf{策略教师构造}：以未来 \textbf{5d/10d open return} 作为 lookahead oracle 主信号，并融合 VLM 的方向与置信度作为小权重修正，生成每日 \textbf{21维目标仓位}，用于构造组合策略训练标签。
    \item \textbf{组合策略训练}：将 \textbf{Qwen3.5-0.8B} 作为组合状态 encoder，输入当前持仓与20只股票的 VLM JSON 信号，并在特殊 token \textbf{<PORTFOLIO\_DECISION>} 上接入 \textbf{FFN head}，直接输出21维 softmax 仓位；训练目标采用偏 \textbf{utility loss} 的形式，综合收益、换手成本与仓位变化成本。
    \item \textbf{回测验证}：集成 \textbf{StockBench} 回测框架，实现 \textbf{qwen\_portfolio\_policy strategy}，支持加载训练好的 policy，在回测中按日预测目标仓位并生成买卖订单，完成从预测信号到组合交易策略的闭环验证。
\end{itemize}


\textbf{TimeThinkingLLM} \hfill 2025.9 -- 2026.1 \titlebreak
项目描述：本项目面向\textbf{时间序列问答(Time-Series QA)}场景，旨在打通连续时序信号与自然语言逻辑推理之间的模态鸿沟。项目构建了基于\textbf{Temporal Encoder + LLM Backbone}的时序推理框架，引入\textbf{重构损失、VLM知识蒸馏与RLVR/GRPO强化学习}，提升大语言模型对趋势、异常、周期等时间序列模式的感知与推理能力。
\begin{itemize}[nosep, topsep=\intraProjectListTopSep]
    \item \textbf{模型架构}：独立设计并实现了基于 \textbf{MLP-Mixer} 的\textbf{时序编码器}，融合 Token-Mixing、Channel-Mixing、统计特征注入与可学习位置编码，将连续时间序列映射到 \textbf{Qwen-3} 等大语言模型可理解的语义嵌入空间。
    \item \textbf{模态对齐与训练}：设计了 \textbf{动态Embedding注入机制}，将时序特征无缝嵌入文本指令序列；同时引入基于 \textbf{Pearson Correlation} 的趋势感知重构损失，使模型在对齐过程中更关注序列形态与变化趋势，而非单点数值误差。
    \item \textbf{推理能力增强}：构建了从\textbf{模态预训练、联合微调、CoT监督微调到GRPO强化学习}的四阶段训练流程，并利用 \textbf{VLM} 生成时序趋势分析、异常检测、周期判断等\textbf{链式推理数据}，增强模型的复杂时间序列推理能力。
    \item \textbf{实验评估}：在 \textbf{ChatTS Eval A/B、TimeSeriesExam、MCQ} 等时间序列理解与推理基准上完成系统评测，并围绕编码器收敛、模型容量限制与CoT稳定性进行了深入误差分析，为后续数据扩展、VLM-as-a-Judge奖励建模和大模型骨干迁移提供实验依据。
\end{itemize}

\textbf{CUARewarder} \hfill 2026.3 -- 2026.5 \titlebreak
项目描述：本项目面向 \textbf{GUI Agent} 的轨迹评估与奖励建模场景，旨在将网页/桌面操作类任务的执行过程转化为可自动评估的 \textbf{judge/reward 信号}。项目以任务目标、截图序列、Agent 动作历史及可选推理说明为输入，结合 \textbf{VLM} 与多种 judge 后端，对 Agent 是否真实完成任务进行自动化判定，并生成结构化奖励结果，可用于 Agent 评测、Reward Modeling 及 RL 训练数据构建。
\begin{itemize}[nosep, topsep=\intraProjectListTopSep]
    \item \textbf{轨迹数据处理}：设计并实现了面向 GUI Agent 的\textbf{任务轨迹解析与批量处理流程}，支持对操作截图序列、动作历史、任务目标及推理/操作说明进行统一组织与标准化输入。
    \item \textbf{自动化评估模块}：构建了基于 \textbf{VLM} 与多种 judge 后端的\textbf{轨迹评估机制}，综合截图状态变化、动作执行路径和任务目标完成情况，判断 Agent 在复杂交互场景下的真实任务完成度。
    \item \textbf{奖励信号生成}：将轨迹评估结果转化为结构化的 \textbf{judge/reward 输出}，相比仅依赖最终文本答案或字符串匹配的传统评估方式，更准确地刻画 GUI Agent 的操作过程质量与任务完成效果。
    \item \textbf{核心产出}：完成了从\textbf{轨迹采集、截图理解、动作历史分析到奖励信号生成}的 GUI Agent 评测闭环，为后续 Agent Benchmark、Reward Modeling 与 RL 训练数据构建提供了可复用的基础模块。
\end{itemize}
